# bankrotstvo70.ru — новый сайт

Сайт арбитражного управляющего Ю. А. Антонца (Томск). Замена старого WordPress.

**Стек:** Astro 7 (статическая сборка) · Tailwind CSS 4 · TypeScript · PHP-обработчик заявок (`public/lead.php`).
Почему так — `seo/decisions.md`.

## Команды

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # готовый сайт в dist/
npm run preview   # посмотреть собранную версию
```

## Где что менять

| Что | Файл |
|---|---|
| Контакты, цены, правовые цифры, дела, меню | `src/data/site.ts` — **единственный источник фактов** |
| Прайс юруслуг | `src/data/prices.ts` |
| Тексты страниц | `src/pages/**` |
| Шапка, подвал, мета-теги, schema.org | `src/layouts/Base.astro`, `src/data/schema.ts` |
| Форма заявки, квиз | `src/components/LeadForm.astro`, `src/components/Quiz.astro` |
| Редиректы со старого сайта | `public/.htaccess` |

## Публикация на обычный хостинг (Apache + PHP)

1. `npm run build`.
2. Залить содержимое `dist/` в корень сайта (вместо WordPress; старую БД и файлы сохранить в архиве).
3. На хостинге скопировать `lead-config.example.php` → `lead-config.php`, указать почту и, по желанию, Telegram-бота.
4. Проверить: отправить тестовую заявку; открыть старый адрес статьи (`/2020/01/23/…`) — должен быть 301 на новую.
5. В Яндекс Вебмастере и Google Search Console: отправить `https://bankrotstvo70.ru/sitemap-index.xml`, проверить отсутствие ошибок.

## Что сознательно НЕ перенесено со старого сайта

- Отзывы и «клиенты» из БД — это отзывы о лестницах и логотипы из чужого шаблона.
- PDF определений судов — в них персональные данные должников (адрес, ИНН, СНИЛС). Номера дел оставлены, их можно проверить в картотеке.
- Скан свидетельства 1999 г. — на нём паспортные данные и домашний адрес.
- «Акция месяца −15 %» и «скидка 5 %» — без срока действия это недостоверная информация.
- Устаревшие правовые сведения 2020 года (порог 300 000 ₽ для ООО, «законопроект о внесудебном банкротстве» и т. п.) — заменены актуальными.
