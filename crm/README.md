# CRM bankrotstvo70.ru

Заявки с сайта и заходы посетителей: кто пришёл, откуда, какие страницы смотрел, что нажимал и после чего оставил заявку.
Основа — CRM «Авто-Вираж» (`Новый дизайн виража/virazh-tomsk-site/crm`, 25.11.2026); перенесены счётчик заходов, админка,
вход и журнал. **Не перенесены** (пока не нужны): SMS, бот и чат MAX, ИИ-чат, очередь звонков и график попыток,
напоминания, уведомления в Telegram, настройки текстов. PHP 8.1+ без фреймворков, база SQLite (MySQL — по желанию, `DB_DSN`).

## Как устроено

| Где | Что |
|---|---|
| `public/js/visits.js` (сайт) | счётчик на всех страницах: просмотры, время на экране, прокрутка, нажатия на телефон, почту, MAX/Telegram/WhatsApp, маршрут, форма заявки (только факт, без значений полей), тест. Шлёт на `/api/visit`. Cookie `sd_vid` (12 мес.) и `sd_sid` (30 мин.) |
| `public/lead.php` (сайт) | приём заявки как раньше (почта, MAX) + запись в CRM `Leads::createFromSite` с привязкой к заходу по cookie |
| `public/crm.php` (сайт) | вход: находит `~/bankrotstvo70-crm` и передаёт запрос в `App\Routes` |
| `public/.htaccess` | `/crm…` и `/api/visit` → `crm.php` |
| `crm/` → `~/bankrotstvo70-crm` на хостинге (вне сайта) | код, шаблоны, миграции, cron, `.env`, `storage/` (база, логи, сессии) |

Формат данных счётчика — `docs/visits-api.md`.

## Админка `/crm`

- **Заявки** — список с поиском и фильтрами, карточка: статус (Новая / В работе / Стал клиентом / Отказ / Спам),
  «Как действовал на сайте» (страницы и действия захода с заявкой), «Путь клиента» (все заходы), комментарии, другие заявки с номера.
- **Заходы** — график по источникам, список, «сейчас на сайте», страница захода с путём по сайту.
- Руководителю: **Отчёты** (заявки по статусам и источникам, сайт: люди, источники, страницы входа, где уходят),
  выгрузка заявок в CSV, удаление заявки, **Сотрудники**, **Журнал** действий.
- Вход по логину и паролю (хеш), 5 попыток на логин / 20 с IP за 15 минут, CSRF, просмотры заявок пишутся в журнал.

Видеозаписи экрана нет: «как действовал» — это хронология страниц и действий. Видео — Вебвизор Яндекс Метрики
(если подключить, в заходе виден ClientID `_ym_uid` для поиска записи).

## Сроки хранения (152-ФЗ)

Заходы без заявки — 3 месяца (`VISITS_RETENTION_MONTHS`), заявки, по которым человек не стал клиентом, — 12 месяцев
после последнего изменения (`LEADS_RETENTION_MONTHS`), вместе с их заходами. Удаляет `cron/run.php` раз в сутки в 03:xx.

## Локально

```bash
cp crm/.env.example crm/.env                     # APP_ENV=local — база создаётся сама
npx astro build --outDir <папка>                  # собрать сайт
php -S localhost:8797 -t <папка> crm/dev-router.php   # http://localhost:8797/crm
CRM_PASSWORD=... php crm/database/create-manager.php логин "Имя"   # первый руководитель
```

## Хостинг REG.RU (только после «да» владельца)

1. Код: `crm/` → `~/bankrotstvo70-crm` (без `.env` и `storage/`), сайт с `crm.php`, `js/visits.js`, новым `.htaccess` и `lead.php` → `~/www/bankrotstvo70.ru`.
2. `~/bankrotstvo70-crm/.env`: `APP_ENV=production`, `APP_URL=https://bankrotstvo70.ru`, `chmod 600`.
3. `/opt/php/8.3/bin/php ~/bankrotstvo70-crm/database/migrate.php`.
4. Cron в ispmanager («Планировщик CRON»), раз в минуту:
   `/opt/php/8.3/bin/php /var/www/u3742554/data/bankrotstvo70-crm/cron/run.php >/dev/null 2>&1`
5. Первого руководителя создаёт владелец сам (пароль вводит он):
   `/opt/php/8.3/bin/php ~/bankrotstvo70-crm/database/create-manager.php логин "Имя"` — роль `manager`; третий параметр `admin` — рядовой сотрудник без отчётов и журнала.
